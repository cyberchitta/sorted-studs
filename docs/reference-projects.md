## Model Architecture Research

| Resource                                 | Key Finding                                                                                                                                                                                                         | Links                                                                                 |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| ConvNeXt V2 (Woo et al.)                 | Masked autoencoder pretraining + Global Response Normalization for CNNs. Model variants from Atto (3.7M params) to Huge (650M). SOTA pure CNN.                                                                      | [HuggingFace](https://huggingface.co/docs/transformers/en/model_doc/convnextv2)       |
| Backbone Comparison (arxiv 2406.05612)   | ConvNeXt-Tiny consistently outperforms EfficientNetV2-S, Swin-Tiny, and others in resource-efficient fine-tuning across domains. Higher ImageNet pretraining accuracy does not predict higher fine-tuning accuracy. | [arXiv](https://arxiv.org/abs/2406.05612)                                             |
| Gołda et al. — LEGO Brick Classification | Compared 28 classification models on 447-class LEGO dataset with high inter-class similarity. Directly relevant to architecture selection.                                                                          | [Springer](https://link.springer.com/chapter/10.1007/978-3-031-08757-8_52)            |
| Multi-view CNN Fusion (PLOS ONE)         | Systematic evaluation of fusion strategies. Late fusion by feature concatenation + one FC layer yields best accuracy with fewest additional parameters. Outperforms score fusion and deep feature map fusion.       | [PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0245230) |
| Brickognize Research Paper               | Photo-realistic synthetic data + Mask R-CNN. Synthetic pretraining + 10 real images exceeds 90% segmentation AP50. Demonstrates synthetic-to-real bridge.                                                           | [MDPI Sensors](https://www.mdpi.com/1424-8220/23/4/1898)                              |

## Apple Neural Engine & On-Device Deployment

| Resource                    | Key Contribution                                                                                                                                                                                                          | Links                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| maderix/ANE (Manjeet Singh) | Reverse-engineered ANE private APIs (`_ANEClient`, `_ANECompiler`). Direct dispatch bypasses CoreML for 2–4× throughput. Documented true M4 peak: 19 TFLOPS FP16 at 2.8W. Trained transformer on inference-only hardware. | [GitHub](https://github.com/maderix/ANE), [Blog](https://maderix.substack.com/p/inside-the-m4-apple-neural-engine) |
| Orion (arxiv 2603.06728)    | First open end-to-end system for direct ANE execution + training. Catalogs 20 MIL IR constraints including GELU→tanh requirement, concat prohibition, tensor layout restrictions. Built on maderix foundation.            | [arXiv](https://arxiv.org/abs/2603.06728)                                                                          |
| ANEMLL                      | Practical ANE-optimized inference pipeline. Converts HuggingFace models to ANE-optimized CoreML. Up to 10× faster, 14× lower peak memory vs. baseline. iOS/macOS/visionOS support.                                        | [GitHub](https://github.com/Anemll/Anemll), [Website](https://www.anemll.com/)                                     |
| hollance/neural-engine      | Community documentation of ANE capabilities, supported devices, and per-chip TOPS specs across all Apple Silicon.                                                                                                         | [GitHub](https://github.com/hollance/neural-engine)                                                                |
